# 정밀 성격 유형 진단

네 축(E/I, S/N, T/F, J/P)이 고르게 섞여 있어 짧은 검사로 유형이 잘 잡히지 않는 사람을 위한 자기보고식 진단입니다.

## 첫 화면

1. 대표 이미지(`assets/hero.jpg`, 1536×1024 · 모바일용 `assets/hero-1200.jpg`)
2. 네 축 여덟 지표 안내 — 영문 원어·한글 뜻·핵심 차이
3. 16유형 — 분석형(NT)·외교형(NF)·관리자형(SJ)·탐험가형(SP) 탭, 4유형씩 카드
4. 검사 팁 네 가지(평소의 나·쉴 때의 나·2나 4·첫 느낌)
5. `자세한 검사 시작하기` — 히어로와 하단 두 곳

## 페이지

- `index.html` — 일반사람용. 가족·지인·누구나 쓰는 판.
- `clinic.html` — 진료실·한의사 맥락 표현이 들어간 이전 판(보관용).

주소
- 일반사람용: https://mujusang.github.io/mbti-test/
- 보관용: https://mujusang.github.io/mbti-test/clinic.html

## 문항 방식

문항마다 세 부분으로 읽힙니다.

1. 장면 — 회색 글씨로 1~2문장. 실제로 겪을 만한 구체적인 상황.
2. 물음 — "이때, 더 자연스러운 쪽은?" 한 줄.
3. 두 반응 — 왼쪽 문장과 오른쪽 문장. 한쪽을 누르면 그쪽으로 완전히 기울인 답(1 또는 5)이 되고, 아래 1~5에서 정도를 고를 수 있습니다.

## 구성

- 40문항: 4축 각 8문항(일·공부할 때 4 + 평소·쉴 때 4, 왼쪽 극 4:4로 위치 편향 상쇄) + 인지기능 8문항(서로 대비되는 기능 네 쌍 × 2문항)
- 40문항을 마치면 축 점수가 50에서 10포인트 안쪽인 경계축마다 양자택일 결정 문답 1문항(최대 4문항)이 자동으로 나옵니다. 결정 문답은 세 문항분 무게로 계산해 표면 성향과 판단 코어를 가릅니다.
- 결과: 코어 유형과 검사지 표면 유형, 4축 퍼센트 게이지(검사지 점수는 가는 선으로 표시), 일할 때와 평소의 차이, 인지기능 8종 상대 지수, 추정 주기능·부기능, 경계축 결정 문답 정리
- `결과 복사` 버튼으로 장면과 고른 답 40개, 결정 문답까지 담은 결과 전문을 순수 텍스트로 복사
- 외부 의존성 없는 단일 `index.html` (순수 HTML/CSS/JS), 모바일 우선

자기보고식 진단이며 의학적 진단이 아닙니다.

## 배포

    ./deploy.sh mbti-test

deploy.sh가 index.html·clinic.html·README.md·assets/를 복제해 push하고, Pages 상태와 본문·대표 이미지 응답을 확인합니다.
