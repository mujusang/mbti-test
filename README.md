# 정밀 성격 유형 진단

네 축(E/I, S/N, T/F, J/P)이 고르게 섞여 있어 짧은 검사로 유형이 잘 잡히지 않는 사람을 위한 40문항 자기보고식 진단.

- 4축 각 8문항(일할 때 4 + 평소 4) + 인지기능 8문항, 5단계 척도
- 결과: 4축 퍼센트 스펙트럼과 경계축, 일할 때와 평소의 차이, 인지기능 8종 상대 지수, 추정 주기능·부기능
- `나래에게 보낼 결과 복사` 버튼으로 응답 40개를 포함한 결과 전문을 순수 텍스트로 복사
- 외부 의존성 없는 단일 `index.html` (순수 HTML/CSS/JS), 모바일 우선

주소: https://mujusang.github.io/mbti-test/
